# FPV Drone Builder Premium v2 — что сделано

Это первая полноценная переработка загруженного проекта. Она не является финальной версией всего будущего приложения, но уже заменяет старую монолитную основу.

## Главные исправления

- Удалено расхождение между каталогом сайта и каталогом backend.
- Все 131 компонента теперь читаются из `data/components.json`.
- Анализ совместимости вынесен в `server/compatibility.js`.
- Auto build больше не выбирает просто самые дешёвые детали.
- Добавлены проверки рамы/пропеллеров, ESC, аккумулятора, KV, веса VTX, антенны и тяговооружённости.
- Добавлена оценка совместимости от 0 до 100.
- Добавлено сохранение сборок и получение по уникальной ссылке/ID.
- Закрыто публичное добавление компонентов без административного ключа.
- Добавлены rate limit, CORS allowlist, CSP и валидация запросов.
- Полностью переделан внешний вид сайта и мобильная адаптация.
- 3D-превью реагирует на размер рамы, батарею, видео, ducts и payload.
- Добавлены PWA manifest и service worker.

## Как запустить

```bash
npm install
npm start
```

После этого открыть:

```text
http://localhost:3000
```

## Как проверить

```bash
npm run check
```

## Как заменить проект на GitHub

1. Сделать резервную копию старого репозитория или создать отдельную ветку.
2. Удалить старые файлы из рабочей папки репозитория.
3. Скопировать содержимое этого пакета в корень репозитория.
4. Не загружать папку `node_modules`.
5. Выполнить:

```bash
npm install
npm run check
git add .
git commit -m "Rebuild FPV Drone Builder foundation"
git push
```

## Перед публичным запуском

- Создать адрес `support@buildyourownfpv.com` или заменить его в legal-страницах.
- В Render установить правильные `SITE_URL` и `ALLOWED_ORIGINS`.
- Перенести сохранённые сборки из JSON в PostgreSQL/Supabase.
- Проверить права на изображения товаров и заменить hotlinks локальными WebP/AVIF.
- Проверить характеристики компонентов по официальным источникам.
